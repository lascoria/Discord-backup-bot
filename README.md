# Discord-backup-bot
This is a discord bot src where you can create a backup of your own server and it will be saved on your computer .
Commmands :
/backup save mybackup =  saves everything to a JSON file on Desktop

/backup restore mybackup = deletes ALL channels/roles and recreates from backup

/backup list  = shows all saved backups

/backup delete mybackup = deletes a backup file


How to use ?
Creat ur application https://discord.com/developers/applications and paste ur bot token on the source code bot.run("YOUR TOKEN HERE") and run it on vs , once u do that just add the  bot into ur server and it should be online .

Note :
- the bot only works on pc not in mobile even if the bot is online .
- the bot will be always online if the script is still running on vs.
